## 直接使用

将一张图片拖到[自动处理原理图.cmd](D:/大四上/EDA/EIT&BTD/component_lab/自动处理原理图.cmd)，即可本地检测、保留原始候选、生成复核队列及交互预览，并打开结果。无需先制作标签。蓝框为YOLO基线，橙框为候选；不是人工真值。默认只在本机处理。

程序入口也支持文件夹：

```powershell
.\.venv-yolo\Scripts\python.exe scripts/run_automatic_components.py --images "图片或文件夹路径" --output outputs/my_auto_run --device 0
```

需要实际Qwen旁路建议时加 `--qwen --max-calls 8 --token-budget 20000`。默认采用单候选请求、tight256/context512等比补白；达到预算后保留剩余候选。相同输出目录可重放已有缓存，图像SHA或模型配置变化会拒绝混用。

## 自动执行的流程

```text
已有人工修正数据＋固定验证数据
  → 数据及SHA检查
  → 完整元件裁块／全图对照数据
  → 相同预算训练control和mixed
  → 自动对比原验证集成绩

原始图片或验证图
  → 整图＋重叠切片
  → 保留原始框和切片边缘信息
  → 去除完全重复，标记重叠／包含／局部冲突
  → 导出候选紧框＋标明目标的上下文
  → Qwen给出保留／拒绝／不确定及原因
  → 旁路评估、缓存、用量和差异报告
```

1. **自动裁块。** 先以GT规划窗口；凡与窗口相交的已标注元件，都必须完整包含。通过移动／扩展窗口仍不能安全截取时退回全图，并记录原因。验证和测试不切成训练样本。
2. **公平训练对照。** control每原图两份全图，mixed每原图一份全图和一份安全裁块尝试，两组每轮466样本、相同初始权重和6轮预算。有效裁块比例单独统计，不把回退全图算作局部样本。
3. **候选不丢历史。** 保存内部切片边缘框、坐标、分数、来源和哈希。把“是否去掉某个框”变成可重放的策略，而不是推理时永久删除。
4. **自动复核。** 优先处理低分、单路检出、包含／重叠冲突和边缘候选。Qwen要判断完整实例、重复、父子图形和框范围，不只分类。OCR可另行接入，首轮不把原标签文字伪装成OCR结果。
5. **不确定自动留存。** API失败、预算耗尽和不确定均保留原候选并单独标记；不静默丢掉目标，也不把它们从统计分母中去掉。可继续处理其他本地阶段。
6. **结果自动隔离。** 机器建议保存为shadow／silver，不写回人工accepted/rejected，不叫human_verified，不凭模型自信自动改验证答案。更差的模型保留实验记录，现有模型可继续用。

## 本轮如何测试Qwen

固定32候选：16个来自原val、按分数分层；另16个是已有人工审核记录中的8个原框未移动的保留例和8个被删除的难例。后者包含重复框和IC局部图形，并不都代表“图里没有元件”。

用于API的输入manifest与本地评价参考分开保存。请求只含图像、目标框与邻近候选关系，不含人工结论和GT。初试每请求2个候选，发现模型有时只返回单项，后续改为单候选＋等比补白；两阶段合计仍限制16次请求、60000 token预算、每请求最多1200输出token。失败候选不重试，成功结果按输入和prompt哈希复用。未截断的旧模型输出可离线独立校验恢复，不能因此声称原整批成功。

这32例用于验证程序和发现错误，不能据此宣称全量达到95%。正式验证需要完整独立图片；原PCBnet几何标签存在已发现的口径问题，因此同时保留原基准和单独审计记录。

本次两阶段累计16请求，得到17条独立有效结果（含4条离线恢复）；其他候选保留并标记。单候选补白模式7/7请求正常，但4个人工删除难例仍被保留，且拒绝了1个人工保留例。这个选择性试验不支持自动启用Qwen删框。[实测报告](D:/大四上/EDA/EIT&BTD/component_lab/outputs/automation_round_001/qwen_pilot/report/REPORT.md)

## 更能减少人工的后续数据路线

优先利用已经下载的原生KiCad工程：解析符号实例、位置、旋转和单位，计算可追溯的符号几何，再与同页渲染图校准坐标生成YOLO框。按原项目先划分训练／验证，再生成不同分辨率、配色和局部视图。

KiCad官方CLI支持原理图SVG等导出，但不直接提供本项目约定的YOLO框；几何投影、隐藏对象、分单元器件和端口范围仍需工程校验。本机当前未检测到 `kicad-cli`，这一阶段尚未执行。[KiCad官方CLI文档](https://docs.kicad.org/9.0/en/cli/cli.html)

对于没有原生文件的图片，YOLO、Qwen和规则可自动产生带来源的伪标签，难例进入机器待处理区。伪标签可以减少人工工作，但两个模型一致不等于独立真值，也不能据此证明双95%。
